# botc-grimoire

A private Storyteller tool for **Blood on the Clocktower — Trouble Brewing**.

Runs entirely in the browser (React + Vite, `localStorage`, no backend, no accounts).
It is not a game client for players — it is the Storyteller's Grimoire, night-order
sheet, information calculator and notebook, plus a locked-down **Spy Mode** screen you
can hand to the Spy.

- Design spec: [`docs/superpowers/specs/2026-09-07-botc-storyteller-app-design.md`](docs/superpowers/specs/2026-09-07-botc-storyteller-app-design.md)

Status: **design v3, no implementation yet.**
